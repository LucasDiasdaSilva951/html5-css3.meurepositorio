Sobre o Museu

História do Museu

O Museu dos Personagens foi criado como um projeto para reunir informações sobre alguns dos personagens mais marcantes da cultura pop. Cada página apresenta detalhes sobre suas histórias, habilidades, equipamentos e curiosidades, permitindo conhecer melhor suas trajetórias. Além de homenagear grandes personagens da ficção, este projeto foi desenvolvido como exercício de HTML5 e CSS3, colocando em prática diversos conceitos estudados durante o curso.
